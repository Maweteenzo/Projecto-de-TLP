# 💻 Projecto de TLP

> Projeto académico desenvolvido no âmbito da disciplina de **TLP (Técnicas de Linguagem de Programação)**.

Este repositório reúne o trabalho realizado para a disciplina, com foco na prática de programação, na organização do código e na aplicação dos conceitos aprendidos durante as aulas.

## 🎯 Objetivos

- Aplicar conceitos fundamentais de programação.
- Desenvolver o raciocínio lógico e a resolução de problemas.
- Praticar a escrita e a organização de código.
- Registar a evolução do projeto através do Git e do GitHub.

## 🛠️ Tecnologias

- **Linguagem:** C
- **Controlo de versões:** Git e GitHub

## 📁 Estrutura do projeto

A estrutura dos ficheiros pode ser consultada na secção **Code** deste repositório. Os nomes e a organização podem evoluir à medida que o projeto é desenvolvido.

## ▶️ Como consultar

1. Abre os ficheiros na secção **Code**.
2. Consulta o código-fonte e os comentários disponíveis.
3. Se quiseres executar o programa, utiliza um compilador C compatível com o teu sistema.

Exemplo de compilação com GCC, caso o projeto contenha um ficheiro `.c`:

```bash
gcc main.c -o programa
./programa
```

> **Nota:** substitui `main.c` pelo nome real do ficheiro principal. No Windows, podes executar `programa.exe`.
